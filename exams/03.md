## 1. Feladat: Immutable Pont osztályok és konverzió

Készítsen két C++ osztályt síkbeli pontok ábrázolására:

1. `CartesianPoint` derékszögű ($x, y$) koordinátákkal
2. `PolarPoint` polárkoordinátákkal ($r, \phi$)

### Követelmények:

* **Immutabilitás:** Az osztályok legyenek *immutable*-ek, azaz az adattagjaik legyenek privát konstansok.
* **Konstruktorok:** Mindkét osztálynak legyen:
    * Paraméteres konstruktora, amely a saját reprezentációjához tartozó adatokat kapja meg.
    * Konverziós konstruktora, amely a másik típusú objektumból hoz létre példányt (koordináta-átváltással).


* **Getterek:** Biztosítson állandó (const) lekérdező metódusokat az adatokhoz.
* **Szögek kezelése:** A szög ($\phi$) radiánban értendő és feltételezzük, hogy a $(-\pi, \pi]$ intervallumba esik. Használhatja a `cmath` fejállományban lévő függvényeket.

### Kétirányú koordináta-átváltás képletei:

* **Derékszögű $\rightarrow$ Polár:**

$$r = \sqrt{x^2 + y^2}$$


$$\phi = \text{atan2}(y, x)$$


* **Polár $\rightarrow$ Derékszögű:**

$$x = r \cdot \cos(\phi)$$


$$y = r \cdot \sin(\phi)$$



### Teszteléshez használható kódrészlet:

```cpp
bool approx(double a, double b, double epsilon = 1e-5) {
    return std::abs(a - b) < epsilon;
}

int main() {
    CartesianPoint c1(3.0, 4.0);
    PolarPoint p1(c1);

    if (!approx(p1.r(), 5.0)) {
        return false;
    }
    if (!approx(p1.phi(), atan2(4.0, 3.0))) {
        return false;
    }

    PolarPoint p2(10.0, 2.2);
    CartesianPoint c2(p2);

    if (!approx(c2.x(), 10.0 * cos(2.2))) {
        return false;
    }
    if (!approx(c2.y(), 10.0 * sin(2.2))) {
        return false;
    }

    return 0;
}

```

## 2. Feladat: Mutable PolarPoint és Kivételkezelés

Készítsen egy `PolarPoint` nevű C++ osztályt síkbeli pontok polárkoordinátás ábrázolására.

### Követelmények:

* **Az osztály adattagjai:**
    * `r` – sugár
    * `phi` – szög (double, radiánban)


* **Mutabilitás:** Az osztály *mutable*: legyenek setter metódusok az adattagok módosítására.
* **Az osztály biztosítson továbbá:**
    * paraméteres konstruktort
    * gettereket az adattagok lekérdezésére


* **Invariánsok:** Az osztály tartsa be az alábbi invariánsokat (jellemzőket, tulajdonságokat):
    * $r \ge 0$
    * $\phi \in (-\pi, \pi]$


* **Kivételkezelés:** * Ha az invariáns sérül: a konstruktor vagy setter váltson ki a hibára megfelelően utaló típusú kivételt.
* A setterek **nem módosíthatják az objektum állapotát**, ha kivétel keletkezik (tranzakcionális működés).


* **Tesztelés:** Tesztelje, hogy a kivételek mindig létrejönnek, amikor kell, és nem jönnek létre megfelelő adatok esetén.

## 3. Feladat: Polimorfizmus és Absztrakt Ősosztály

Készítsen egy absztrakt `Point` ősosztályt, és két leszármazottat: `CartesianPoint` és `PolarPoint`.

### Követelmények:

#### 1. `Point` ősosztály

* Legyen **absztrakt**.
* Publikus, polimorf metódusok:
    * `distanceFromOrigin()` – az origótól mért távolság.
    * `print()` – a pont adatait írja ki a standard kimenetre.
* Virtuális destruktor.

#### 2. Leszármazott osztályok (`CartesianPoint` és `PolarPoint`)

* **Mutable osztályok:** adattagok privátak, legyenek getterek és setterek.
* Konstruktor, amely beállítja a koordinátákat.
* `CartesianPoint` adattagok: `x`, `y`
* `PolarPoint` adattagok: `r`, `phi` (radiánban). *Feltételezzük, hogy phi helyes, a $(-\pi, \pi]$ intervallumban van, nem kell ellenőrizni.*

#### 3. Polimorf használat

* Készítsen egy dinamikus tömböt az **STL** használatával és tároljon benne különböző típusú pontokat!
* Iterálva hívja meg a `distanceFromOrigin()` és `print()` tagfüggvényeket!

## 4. Feladat: Operátor felültöltés és Láncolt lista (Töröttvonal)

Készítsen egy `CartesianPoint` nevű C++ osztályt síkbeli pontok derékszögű koordinátás ábrázolására.

### Követelmények:

1. Az osztály **immutábilis** legyen: az adattagok legyenek privát konstansok, ezért most setter tagfüggvények sem kellenek.
2. Az osztály adattagjai:
    * `x` – x koordináta (double)
    * `y` – y koordináta (double)


3. Az osztály biztosítson:
    * paraméteres konstruktort
    * konstans getter metódusokat az adattagok lekérdezésére (`x()`, `y()`)


4. Töltse felül az alábbi operátorokat:
    * `+` operátor: két `CartesianPoint` vektori összeadását valósítsa meg, új objektumot adjon vissza, az operandusok nem módosulhatnak.
    * `<<` operátor: írja ki a pont koordinátáit a standard kimenetre az alábbi formában: `(x, y)`.



## 5. Feladat: STL láncolt lista feladat

* Hozzon létre egy irányban láncolt listát az **STL** segítségével (`std::forward_list`), melynek elemei `CartesianPoint` objektumot címző mutatókat tárolnak, és töltse fel legalább 4 ponttal.
* Írjon egy függvényt az alábbi prototípussal:
```cpp
double polylineLength(std::forward_list<CartesianPoint*> points);

```
