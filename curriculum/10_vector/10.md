# std::vector

Az `std::vector` a modern C++ legfontosabb tárolója. Lényegében egy **dinamikus tömb**, amely egyesíti a hagyományos tömbök sebességét az automatikus memóriakezelés kényelmével.

## 1. Memória-felépítés és működés
A vektor elemei **folytonos memóriaterületen** helyezkednek el. Ez teszi lehetővé a villámgyors elérést index alapján. A háttérben a vektor objektum a **Stack**-en él, de három mutatót kezel, amik a **Heap**-re (halomra) mutatnak:
* **Begin:** Az első elemre mutat.
* **End:** Az utolsó tárolt elem utáni pozícióra mutat.
* **Capacity End:** A lefoglalt blokk legvégére mutat.



---

## 2. Deklaráció és inicializálás
A használathoz a `#include <vector>` és a rendezéshez az `#include <algorithm>` szükséges.

```cpp
std::vector<int> v1;                    // Üres vektor
std::vector<int> v2(5, 100);            // 5 darab 100-as érték
std::vector<int> v3 = {1, 2, 3, 4, 5};  // Inicializáló lista
```

---

## 3. Vektor vs. Pointer vs. Tömb
* **Statikus tömb (`int a[5]`):** Fix méret, a Stack-en él.
* **Dinamikus tömb (`int* a = new int[n]`):** Manuálisan kell felszabadítani (`delete[]`).
* **Vektor:** Automatikusan felszabadítja magát. A `.data()` függvénnyel lekérhető a nyers pointere:
  ```cpp
  int* ptr = v3.data(); // Pointer az első elemre
  ```
> **⚠️ Pointer invalidáció:** Ha elmented egy elem címét, majd a vektor `push_back()` miatt újraméretezi magát, a régi pointered érvénytelenné válik, mert a vektor új memóriacímre költözhetett!

---

## 4. Hatékonyság: Size vs. Capacity
* **Size:** Hány elem van benne most.
* **Capacity:** Mennyi hely van lefoglalva.
Ha a vektor betelik, újrafoglalás történik (másolással), ami lassú. **Megoldás:** `v.reserve(100);` – ha tudod a várható méretet, foglald le előre!



---

## 5. Rendezés (std::sort)
### Alapeset (Egyszerű típusok)
```cpp
std::sort(v.begin(), v.end()); // Növekvő
```
### Komplex objektumok (pl. Point)
Ha saját osztályod van, meg kell adnod a rendezési elvet:
1.  **Operátor felülírással:** Az osztályon belül definiálod a `<` operátort.
2.  **Lambda függvénnyel:** Helyben megadod a szabályt:
```cpp
std::sort(points.begin(), points.end(), [](const Point& a, const Point& b) {
    return a.x < b.x; // X koordináta szerint rendez
});
```

---

## 6. Leggyakoribb függvények példákkal
Nézzük a mindennapi munka során használt legfontosabb metódusokat:

| Függvény | Példa | Leírás |
| :--- | :--- | :--- |
| `push_back` | `v.push_back(10);` | Új elem hozzáadása a végéhez. |
| `emplace_back` | `v.emplace_back(x, y);` | Objektum létrehozása közvetlenül a vektorban (gyorsabb). |
| `pop_back` | `v.pop_back();` | Az utolsó elem törlése. |
| `size` | `if (v.size() > 0)` | Visszaadja az elemek számát. |
| `at()` | `int x = v.at(2);` | Biztonságos elérés (hibát dob, ha rossz az index). |
| `clear` | `v.clear();` | Minden elemet töröl, de a kapacitás megmarad. |
| `empty` | `if (v.empty())` | Igazat ad, ha nincs benne elem. |
| `front / back` | `int f = v.front();` | Az első vagy az utolsó elem elérése. |
| `insert` | `v.insert(v.begin() + 1, 5);` | Beszúrás adott pozícióra (lassú: $O(n)$). |
| `erase` | `v.erase(v.begin());` | Elem törlése pozíció alapján (lassú: $O(n)$). |

---

## 7. Iterátorok (A modern pointerek)
A vektorokat nem indexekkel, hanem iterátorokkal a legszebb bejárni.
```cpp
for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << " "; // Úgy működik, mint egy pointer
}
```

---

## 8. Összetett példaprogram
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> numbers = {30, 10, 50, 20};

    numbers.push_back(40);      // [30, 10, 50, 20, 40]
    std::sort(numbers.begin(), numbers.end()); // [10, 20, 30, 40, 50]

    if (!numbers.empty()) {
        std::cout << "Elso elem: " << numbers.front() << std::endl;
        std::cout << "Utolso elem: " << numbers.back() << std::endl;
    }

    // Törlés: a második elemet (20) kivesszük
    numbers.erase(numbers.begin() + 1); 

    for (int n : numbers) std::cout << n << " "; // 10 30 40 50 

    return 0;
}
```
